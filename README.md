# buildwithshlok.github.io

A responsive, single-page personal landing site for GitHub Pages.

## Publish it

1. Create a **public** GitHub repository named exactly `buildwithshlok.github.io`.
2. Upload `index.html`, `style.css`, and `script.js` to the repository root.
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch `main` and folder `/ (root)`, then save.
6. Wait a few minutes and visit https://buildwithshlok.github.io.

## Customize

- Update your introduction and sections in `index.html`.
- Change colors and layout in `style.css`.
- Social profile links are in `index.html`.
- This version uses Google Fonts; if you want to avoid external font requests, remove the Google Fonts lines from `index.html`.

No build step is required.
